# Student-grading-system
##Overview:
Academic institutions and individual educators routinely record, revise, and review the marks earned by their students. When only a handful of students are involved, this is often done on paper or in ad-hoc spreadsheets, which quickly becomes hard to search and easy to get wrong. This project presents a lightweight Student Grade Management System implemented in Python that lets a user store each student's grade against their name and interact with those records through a simple text-based menu. The application is deliberately console-based and dependency-free so it runs on any computer with a standard Python installation. It demonstrates core problem-solving and programming concepts — dictionaries, user-defined functions, loops, conditional branching, and exception handling — applied to a small but realistic record-keeping problem.
