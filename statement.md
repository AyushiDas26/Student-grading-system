# Student Grades Management System

1. Problem Statement

Keeping track of students' grades manually can be difficult, especially when there are many students. It can also take time to find a student's grade or make changes to their marks.

The Student Grades Management System is a simple Python program that helps users manage student names and grades. It allows the user to add a student, update their grade, and view all the students and their grades through an easy menu.

The main purpose of this project is to make basic grade management simpler and also demonstrate the use of basic Python programming concepts.

2. Scope of the Project

This project focuses on the basic management of student grades using a Python program.

The system can:

* Add new students and their grades.
* Update the grade of an existing student.
* Display all students and their grades.
* Check and handle incorrect input from the user.
* Provide a simple menu so that users can easily choose what they want to do.

For now, the student information is stored temporarily in a Python dictionary. This means the data will be lost when the program is closed. The project does not currently use a database or permanent storage.

3. Target Users

This project can be useful for:

* Students who are learning Python and want to understand how a small management system works.
* Teachers who need a simple way to keep track of student grades.
* Beginners in programming who want to practice concepts such as functions, dictionaries, loops, and conditions.
* Small classes or educational settings** where only a small number of student records need to be managed.

4. High-Level Features

Add Student:

The user can enter a student's name and grade, and the information is added to the system.

Update Grade:

The user can enter the name of an existing student and change their grade.

View All Students:

The system displays all the students currently stored along with their grades.

Input Validation:

The program checks whether the user enters a valid number when selecting an option or entering a grade.

Student Not Found:

If the user tries to update a student who is not in the system, the program displays a message saying that the student was not found.

Simple Menu:

The program provides a simple menu with four options:

1. Add Student
2. Update Grade
3. View All Students
4. Exit

Temporary Data Storage:

The student details are stored in a Python dictionary while the program is running.

Conclusion:

The Student Grades Management System is a small and simple Python project that makes it easier to manage basic student grade information. It also helps beginners understand how different Python concepts can be combined to create a useful program.
